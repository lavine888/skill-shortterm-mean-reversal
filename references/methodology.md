# 方法说明

## 因子定义

决策日 `t` 的过去收益为 `P(t) / P(t-5) - 1`，其中 5 指市场交易日位置，不是自然日，也不是某只股票最近出现报价的第五天。反转分数为过去收益的相反数，分数越高代表过去跌幅越大。

横截面至少需要 20 个有效标的。排序以过去收益为第一键、证券代码为第二键，确保并列值下仍可复现。每组数量为 `floor(N * 10%)`，且至少为 1。

## 点时纪律

信号函数先截断 `date <= decision_date`，并断言截断后的最大日期不超过决策日。策略不使用进场日或退出日信息选股。未来收益只在信号和持仓冻结后用于评价。

## 收益与成本

收益区间是下一市场交易日收盘至其后第五个市场交易日收盘。组合毛收益为实际成交权重乘个股远期收益。进场缺失或受限的目标不成交并保留现金；已成交仓位缺失退出价格时运行失败。Rank IC 对缺少完整端点价格的证券排除并披露覆盖率。

交易成本为 `cost_rate * sum(abs(new_weight - drifted_old_weight))`。旧权重先按持有期收益和成本后的净值漂移，再与新目标比较。初次建仓计成本，最后一个组合按退出时实际名义金额计平仓成本。

融券费用单独建模：`short_fee_rate` 为年化费率，周期模式对空头已成交名义金额收取 `rate * hold_days/252`，`daily_nav` 模式每个交易日按 `rate/252 * 当日空头市值` 收取。费用从净值中扣除并逐日记录，校验器独立重算。

可借券状态通过可选的 `borrowable` 点时布尔列建模：空头目标在进场日不可借时以 `not_borrowable` 阻断并保留现金。缺少该列时能力报告为未建模，空头视为可借。该列只约束新建空头仓位，不阻断已有仓位退出。

推荐的 `daily_nav` 模式使用带符号份额和显式现金：`cash -= fill_units * fill_price + cost`，`NAV = cash + sum(units * close)`。每日先盯市，再重试所有到期退出，随后用退出后剩余的多空预算处理新进场。受限退出保持原份额并逐日重试；同证券有未平仓批次时不重复加仓。期末未退出仓位继续按当日价格计入 NAV，不收取假设平仓成本。

进场日没有有效价格或明确不可交易的目标仓位不成交，资金保留为现金。已经成交的仓位如果退出日缺少价格或明确不可交易，运行直接失败；系统不会用 0% 收益掩盖退市、长期停牌或数据断层。

交易状态按方向处理：停牌证券不能进出，ST 证券不新建仓位但已有仓位仍可退出；多头在涨停不能买入、在跌停不能卖出；空头在跌停不能卖空、在涨停不能回补。阻断目标保留现金，阻断退出继续持有或在周期模式中 fail-closed。该模型只判断收盘价是否达到涨跌停价，不模拟队列中的实际成交概率。

退市是唯一可显式放宽的缺失退出场景。启用 `last_available_close` 后，系统必须从证券主表确认退市日在进场与计划退出之间，才会在退市前最后报价日尝试退出；当日仍需通过停牌和方向性涨跌停检查。周期模式无法成交时 fail-closed；逐日模式继续持仓，但退市后缺少可验证结算估值时同样停止。

退市结算价通过可选的证券级 `delisting_settlement_price` 列建模，与 `de_listed_date` 配对。当持仓标的在持有窗口内确认退市且提供了结算价时，仓位在退市日按该价格结算（`delisting_settlement_exit`），不再 fail-closed。未提供该列时历史 fail-closed 行为不变。结算价是用户必须自行来源与核验的数据输入。

## 指标

- Rank IC：反转分数与同区间个股远期收益的横截面秩相关。
- 年化收益：非重叠 5 日组合收益的几何年化。
- 年化波动与 Sharpe：按每年 `252 / hold_days` 个期间年化，无风险利率取 0。
- 最大回撤：从初始净值 1.0 开始计算。

本实现是收盘到收盘的因子研究诊断，不模拟订单簿排队、融券召回或盘中成交。

当前版本只接受 `rebalance_every == hold_days`，因此各持有期不重叠。重叠组合或调仓间隔大于持有期的情形必须使用逐日 NAV 和多 sleeve 会计。

周期模式保留用于历史比较和完整横截面 Rank IC 证据。逐日模式允许退出延期造成跨期持仓，但仍不支持主动重叠信号 sleeve；被锁定的多头和空头分别占用各自 50% 预算。
